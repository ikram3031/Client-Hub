Portable Drop-in Kit

Integrate docsNlogs into Any Git Project in 60 Seconds

Drop the lightweight client-kit/ folder into any client repository or white-label codebase. Add it to .gitignore so it never pollutes the client's repository. Give the instructions to Antigravity, Gemini, or Claude, and let the AI log commits automatically!

1 Copy Kit & Add to .gitignore

Copy the client-kit directory into your target project and add this line to your project's .gitignore:

# Ignore docsNlogs AI Client Kit
/client-kit/
/.config/

2 Initialize Config (Interactive Wizard)

Run the wizard once inside your client repository:

node client-kit/init.js

AI Assistant System Rule (Antigravity, Gemini, Claude, Cursor)

Copy and paste this instruction into your AI coding assistant prompt or system instructions:

📌 AI COMMIT & CHANGELOG RULE:
Whenever you implement changes, fix bugs, or commit code in this repository:
1. Follow Git Commit Standard: <LogID>(<type>): <description>
   - #AB: Backend changes (e.g. "AB01(feat): add auth endpoint")
   - #AD: Frontend changes (e.g. "AD01(fix): update button style")
   - #AA: Architecture / Doc changes (e.g. "AA01(refc): modularize db")
2. Push your action log to the central docsNlogs hub with one command:
   node client-kit/log.js
   (or: node client-kit/log.js --summary "Short summary" --scope backend --files "path/file.ts")
